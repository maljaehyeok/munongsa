# UI/UX 1차 개선 — 2026-11-14

- 기존 문제: 처음 화면의 행동이 스크롤 아래에만 있었고 질문·조건 검색이 서로 다른 진입이었다. 모바일의 조건 폼과 긴 적용 조건·상시 안내가 입력 공간을 차지했다. 결과 카드의 서류·상세 조건이 길어 공식 링크까지 이동이 길었다.
- 원인: 조건 상태·결과 근거는 있었으나 화면의 기본 노출 순서와 정보 밀도가 핵심 행동에 맞지 않았다. 금액 입력은 비교 전 명시적 적용이 필요한 초안 구조이며, 입력 중 환산값은 표시하지 않았다.
- 개선: 첫 화면의 ‘내 지원사업 찾기’, 상담 내 질문·조건 선택 진입, 별도 전체 공고 탐색을 제공한다. 조건은 중요도 순서로 표시하고 현재 조건은 펼쳐 확인한다. 조건 비우기는 적용 전 입력칸만 비운다.
- 결과: 사업명·비교 이유·기재 모집기간·지원 내용·공식 링크를 먼저 배치한다. 대상·서류·신청 방법과 전체 근거는 펼쳐 확인하며 원문 발췌·승인 요약·미확인을 유지한다.
- 금액: 명시된 백만원·천원 리터럴만 정수 원으로 검증하여 읽기 쉽게 표시한다. 총사업비·개인 한도·단가의 기존 문맥은 유지하며 공유 단위 범위는 그대로 둔다. 원문과 금액 비교 데이터는 변경하지 않는다.
- 검증 범위: PC 1440px·모바일 390/320px의 진입·조건 선택/수정/비우기·카드·공식 링크·필요 자금 적용/Enter/전체 적용/복원·기존 금융 4개/작물 67종을 변경 영향 범위에서 확인한다. 로컬 미리보기와 실제 AWS 결과는 별도의 실행 결과로 구분한다.
- 가치와 한계: 처음 방문한 농업인이 다음 행동과 확인할 정보를 더 쉽게 찾도록 돕는다. 실제 농업인 사용성 평가·일반 GPT 대비 우수성을 입증한 것은 아니다. 실물 모바일 키보드·모든 공고 원문을 전수 재검증한 작업도 아니다.
