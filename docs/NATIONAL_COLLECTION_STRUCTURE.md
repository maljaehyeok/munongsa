# 전국 수집 구조 개선 결과 — 2026-11-18

## 구현 범위

- 기존 기업마당 인증 API를 재사용했다. 별도 기관·정기 수집기·UI를 추가하지 않았다.
- 공식 명세의 지역 해시태그 조회를 최대 3지역·지역당 50건으로 제한해 지원한다. 이번 지역 표본은 기존 자료가 부족한 제주·충북·강원이다. 일반 최신 목록도 유지한다. 지역 태그는 발견용이며 신청 자격으로 쓰지 않는다.
- 출처 품질은 같은 공고의 근거가 있는 대상·자격 지역·지원 내용·신청기간으로 측정한다. 대상과 자격 지역에 높은 우선순위를 주고, 기존 운영 ID와 이전 검토 자료는 상세 요청 전에 제외한다. 정기 수집의 기존 공고 변경 감시는 제외하지 않는다.
- API 사업개요의 명시적 대상/지원 구분을 추출한다. 거주지와 영농지를 모두 요구하는 경우 두 조건을 보존한다. 경영체 등록 기간을 영농 경력으로 해석하지 않는다. 불명확한 선택·예외·부정 조건은 확정하지 않는다.
- 기존 추천 스키마와 남은 미확인 조건을 유지한다. 승인되지 않은 후보는 기존 비교 분류에서도 참고 단계이며 GPT에 자동 편입하지 않는다.

## 실제 확보 및 대조

운영 DB는 SSH와 SQLite `mode=ro`·`query_only`로 필요한 메타데이터만 조회했다. 조회 시 DB **140건**, 공개 **92건**이었다. 운영 파일·환경변수·DB는 수정하지 않았다.

| 항목 | 결과 |
|---|---:|

| 실제 승인·공개·운영 추천 편입 | **0건** |

- 13건은 새 **레코드** 수다. 확정된 서로 다른 신규 사업 13개라는 뜻이 아니다. 보류는 변경 공고 3건, 기존 타출처와 같은 제목 1건, 이번 포털 응답에서 동일 메타데이터를 확인하지 못한 3건이다. 이유는 중복 집계하지 않았다.
- 제목·소관기관 기준 발견 분포: 경남 7·제주 2·경북 2·전북 2건. **자격 지역 확인 분포가 아니다.** 자격 지역은 경남 내 2건만 명시적으로 확인됐으며 11건은 미확인이다. 전국 자격이 확인된 신규 자료는 0건이다. 충북·강원 조회에서는 새 농업 공고를 얻지 못했다.
- 신청기간에 포함되는 13건도 실제 접수 가능 확인으로 계산하지 않는다. 신규 자료 13건 모두 미승인 상태이므로 현재 맞춤 추천에는 사용하지 않는다. 조건 근거 7건에는 타출처 중복 의심 1건이 포함된다.
- 반환 총 350건에는 API·지역 간 중복과 비농업 자료가 있다. 가공 입력 220건은 첫 일반 조회가 이미 농업 관련 20건으로 선별된 결과여서 반환 총량과 분모가 다르다. 이를 별도 신규 수집 건수로 합산하지 않는다.

## 공식 명세와 이용 범위

- [기업마당 API 명세](https://www.bizinfo.go.kr/apiDetail.do?id=bizinfoApi): 인증, 페이지, 지역 해시태그, 사업개요·신청기간 필드를 확인했다. 인증 실패·호출 제한 시 다른 지역으로 재시도하지 않는다.
- [기업마당 저작권 정책](https://www.bizinfo.go.kr/biz/bizd/selectBIZD120View.do): 본문을 자유롭게 재배포할 수 있다고 판단하지 않는다. 상세 HTML은 일시적으로 분석하고 추출 결과는 비공개 작업 자료로만 남긴다. robots 허용을 재배포 허락으로 취급하지 않는다.
- [공공데이터포털 데이터셋](https://www.data.go.kr/data/15157820/openapi.do): 공공누리 제3유형을 확인했다. 기존 `support_guidance.POLICY`를 재사용하여 실제 포털 응답과 제목·ID가 같고 상세 제목이 확인된 경우에만 원형의 제목·출처·공식 링크를 승인 검토 후보로 표시한다. 요약·금액·자격·본문·첨부 공개 권한은 부여하지 않는다. 담당자 승인이 별도로 필요하다.
