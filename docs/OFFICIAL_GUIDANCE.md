# 공식 안내와 맞춤 추천의 분리

## 기존 공고 활용 확대 (2026-11-14)

기관명만으로 이용 허락을 추정하지 않는다. 기존 등록 기관의 공식 페이지에
공공누리 유형이 명시되고 제목·원문 링크가 일치한 경우, 출처·이용 조건을
표시한 원형 그대로의 제목·기관·링크만 안내할 수 있다. 제2·4유형은 현재의
무료·비광고 캡스톤 서비스에서 비상업적 메타데이터 안내로만 이용한다.
서비스를 상업화하기 전 `NONCOMMERCIAL_METADATA_ONLY`를 끄고 재검토해야 한다.
여러 유형이 함께 표시돼 적용 범위를 확정할 수 없으면 자동 공개하지 않는다.

같은 사업의 중복·변경 안내는 양쪽 본문의 검토 버전에 묶어 제외한다.
본문이 달라지면 이전 중복 결정을 그대로 상속하지 않고 재검토한다.
종자대 지원 대상이 아니라고 명시한 유상 종자 구매 안내는 지원사업에서 제외한다.

확인된 필수조건 일부는 `verified_comparisons`로 기존 조건 엔진에 연결한다.
공개 공고의 원래 승인 데이터는 변경하지 않으며 챗봇의 승인·해시 검증도
우회하지 않는다. 조건 비교는 기존 공고 버전과 원문 문구에 묶이고 3일 후
만료된다. 실제 프로필과 일부 조건이 일치해도 나머지 조건은 미확인으로
유지하며 신청 가능·승인을 확정하지 않는다. 이 비교 보완은 독립 조건 검색에
적용하며, 챗봇의 새로운 근거·자격 승인으로 간주하지 않는다.

`comparison-plans.json`과 `guidance-source-decisions.json`은 서버 비공개 검토
설정이며 코드·원문·운영 DB와 분리한다. 매일 기존 수집 후 원문을 다시 확인해
유효한 계획만 사용한다. 첨부파일이나 전체 본문은 공개하지 않는다.

아래는 최초 API 정책 도입 당시의 기록이다.

기본 안내는 신청 가능 판정이 아니다. 기존 DB의 검토 상태와 승인 이력을
바꾸지 않고, 허용된 최소 메타데이터를 목록에 추가한다.

현재 자동 공개 정책은 공공데이터포털 자료 15157820의 공공누리 제3유형을
확인한 제목·기관·공식 링크에만 적용한다. 제목은 API와 DB가 정확히 같아야
하며 원문 링크의 접근 정책, HTTP 응답, 제목 일치를 다시 검사한다.
본문·첨부·새 요약·지원금·자격조건·모집기간은 이 경로로 배포하지 않는다.
화면에는 출처와 이용 조건, 자격·모집 상태 미확인을 표시한다.

- 정책 근거: https://www.data.go.kr/data/15157820/openapi.do
- 조건: https://www.kogl.or.kr/info/licenseType3.do
- 확인일: 2026-11-14

매일 기존 수집 후 `support_guidance.refresh`가 임시 JSON을 검증해 원자적으로
교체한다. 중복·안전성·농업 관련성·공식 API 버전·링크 검사에 실패하면 보류한다.
내보낼 때 DB 상태와 내용 해시를 다시 확인한다. 안내 확인은 3일 후 만료되며,
갱신 실패는 기존 승인 공고의 내보내기나 수집 전체를 차단하지 않는다.

기본 안내 공고는 `official_guidance`, 자격 미검증 상태이며 추천 가능은 항상
거짓이다. `export_support_public.export`와 챗봇의 승인·해시 검증은 변경하지
않는다. 따라서 안내 목록에 추가됐다는 이유만으로 챗봇 근거가 되지 않는다.
다른 출처의 재이용 범위는 자동으로 상속하지 않는다. 정책 확대는 확인 후 수행한다.

운영 파일: 비공개 `official-guidance.json`, `logs/guidance-*.json`.
공개 패키지에는 정책·코드·가상 테스트만 포함하고 실제 근거·DB·키는 제외한다.

## 모집·전국 범위의 검토 사실 (2026-11-14)

서버 전용 `verified-fact-plans.json`은 이미 공개된 공고의 버전·공식 본문 해시와
대조한 신청기간·대상·신청 방법만 보완한다. 공개 JSON의 `verified_facts`는
원래 승인 공고를 변경하지 않는 별도 검토 사실이다. 원문이나 첨부를 재배포하지 않는다.
변경·비공개·원문 불일치·확인 만료 시 적용하지 않으며, 기존 자격 승인과
챗봇 근거·해시 검증을 대신하지 않는다. 일부 조건의 일치는 전체 자격 확정이 아니다.

전국 표시는 공식 공고의 국내 전체 지역 분류와 신청 대상 문구를 대조한 모집
범위다. 농촌 기반·업력·수출 이력 등 개별 자격은 별도로 확인한다.
운영기관의 현재 모집 안내와 지원 페이지 확인은 24시간 후 만료된다.
로그인 이후 최종 제출을 검증하지 않은 경우 이를 명시한다. 나머지 공고는
날짜상 모집기간·예정·경과와 실제 접수 가능 여부를 계속 구분한다.
