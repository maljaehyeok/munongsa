## 자료 및 재현

실제 결과는 Git에서 제외되는 `work/national-collection-20261117/`에 보존한다.

- `rda-result.json`, `koat-result.json`: 기존 수집기의 원문 전체 미저장 결과, 출처별 사실 근거와 확인일
- `public-baseline.json`: 읽기 전용으로 조회한 AWS 공개 목록
- `candidates.json`: 공식 ID·링크·기관·사실 근거·조건 후보·미확인 항목·비공개 검토 상태

기존 수집 결과로 검토 파일만 재생성하는 명령(네트워크·승인·운영 DB 작업 없음):

```powershell
python -B scripts/collect_national_candidates.py --baseline work/national-collection-20261117/public-baseline.json --result work/national-collection-20261117/rda-result.json --result work/national-collection-20261117/koat-result.json --output work/national-collection-20261117/candidates.json
```

실제 수집은 기존 RDA·KoAT 어댑터와 전송 계층을 사용했다. 로컬 결과 파일에만 기록했고 정기 수집은 중복 실행하지 않았다. robots 접근 허용을 원문·첨부 재배포 허락으로 간주하지 않는다.
