## 줄바꿈과 무결성

다음 8개 파일은 `.gitattributes`의 `-text`로 검증된 Git 원본 바이트를 보존한다. 전역 Git 설정은 변경하지 않는다.

```text
assets/amount-display.js
assets/ux-first.css
assets/personalization.js
assets/notice-review.js
assets/support-details.js
scripts/rag_nlu.py
scripts/rag_catalogue.py
scripts/support_notice_review.py
```

임의 공백·줄바꿈을 허용해 검증을 통과시키지 않는다. SHA-256은 실제 파일 바이트에 적용한다. 소스가 의도적으로 바뀌면 변경 검토 후 해당 해시만 갱신한다. 비공개 근거 해시는 임의로 갱신하지 않는다.

```powershell
python -B -m unittest discover -s deploy/chatbot -p test_checkout.py
```

## 기존 자료 판단

- 공개 저장소의 `assets/support-details.json`은 11건이다. 기존 작업본의 공통 11건은 같고, 추가 8건과 링크 확인 이력 90건이 더 있다. 기존 파일은 운영 웹 데이터 해시와 일치하지만, 이것만으로 현재 승인·공개 권한·접수 상태를 재확인한 것은 아니다.
- 추가 자료는 기존 위치에 보존한다. 신규 저장소에 자동 병합하지 않는다. 웹 데이터와 API의 비공개 근거 파일은 같은 파일명이어도 서로 다른 자료다.
- 공개 피드의 빈 기본 JSON을 운영 공고 0건으로 해석하지 않는다. 실제 공개 피드는 서버의 기존 마운트에서 읽어야 한다.

## 로컬 실행 환경

`.venv`에는 해시가 고정된 Waitress 3.0.2만 별도 설치한다. 수집용 Python과 전역 패키지는 변경하지 않는다. 개발 검사는 기존 Python의 BeautifulSoup 설치를 사용한다. API 키·DB·승인 스냅샷은 복사하지 않는다.

```powershell
.venv/Scripts/python.exe -B -m pip check
```

비공개 근거가 없으면 정상 상담 준비 상태로 표시하지 않는다. 실제 GPT 호출, 승인 공고 답변, Linux systemd·cgroup·네트워크 격리 검증은 로컬 화면 검사와 구분한다.
