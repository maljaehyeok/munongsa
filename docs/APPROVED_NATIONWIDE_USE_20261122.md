# 승인 범위의 실제 운영 반영

- 운영자는 최종 계획 SHA-256 `b8a88d02febbfcba322963bceb3005ba812ddb13ee9dba63536d852e08e0018e`의 기본 안내 43건과 부분 자격조건 9개를 명시적으로 승인했다. 보류 4건·제외 1건·미승인 39항목은 범위 밖이다.
- 기본 안내는 기존 기본사실 확인·참고 공개 승인 도구로 처리한다. 기관은 확인된 공식 기록의 출처기관을 사용하고, API의 광역 분류를 시행기관명으로 임의 대체하지 않는다. 기간·지원금·대상·신청방법은 공개하지 않는다.
- 부분조건은 기존 자격조건 승인 도구와 버전 결속으로 연결한다. 미확인 필수조건은 논리식에 남기며 전체 자격 충족과 접수 가능을 확정하지 않는다. 농지 소재지는 거주지와 별도로 비교한다.
- 제목·기관·링크 승인에는 `metadata_only` 범위를 부여한다. 정기수집의 부가 정보가 이 범위를 확대하지 못하며, 새 상세자료가 GPT 근거로 자동 편입되지 않는다. 기존 공개 공고·상세정보·승인 이력은 보존한다.
- 시군구의 상위 시도는 자격 자체가 아닌 행정구역 관계로만 사용한다. 산청·함안은 [경상남도 공식 시군 자료](https://www.gyeongnam.go.kr/index.gyeong?contentsSid=6786), 화성은 [경기도 공식 행정구역 현황](https://www.provin.gyeonggi.kr/contents/contents.do?ciIdx=468&menuId=1831)과 대조했다. 공고의 발행기관 소재지로 신청 지역을 추정하지 않는다.
- 공개 권한과 자격 승인·판정은 별개다. 신규 공고의 검색과 공식 원문 이동은 허용하되, 자료 부족을 조건 일치나 개인 농업인 대상 추천으로 표시하지 않는다.
