# 공식 지원사업 API 통합 (2026-11-14)

기존 기업마당 검토 출처 하나에 공식 API 두 개를 연결한다. 두 API 모두 AWS에서 HTTP 200과 정상 공고 응답을 확인했다. 같은 50개 공고가 반환되었으며, 공고 ID로 통합했을 때 내용 충돌은 없었다. 이 결과는 전체 데이터의 완전성이나 신청 자격 검증을 의미하지 않는다.

## 인증과 수집

- 기업마당: `BIZINFO_API_KEY`, `crtfcKey`, [공식 명세](https://www.bizinfo.go.kr/apiDetail.do?id=bizinfoApi).
- 공공데이터포털: `DATA_GO_KR_BIZINFO_API_KEY`, `serviceKey`, [공식 명세](https://www.data.go.kr/data/15157820/openapi.do).
- 키는 기존 서버 비밀 설정에서만 주입한다. 인증 URL·원본 응답·예외 본문은 로그에 남기지 않는다. 리디렉션은 따라가지 않는다.
- 포털의 인코딩 키는 한 번만 percent decode한 뒤 URL encode한다. `+`를 공백으로 바꾸지 않는다.
- 각 일일 수집에서 API별 최대 2쪽, 쪽당 50개로 제한한다. 인증·권한·호출 제한 오류를 자동 재시도하지 않는다. 한 API 실패가 다른 API 결과 처리를 막지 않는다.
- 공고 ID와 공식 URL로 중복을 통합한다. 두 제공자의 조건·기간·본문이 충돌하면 해당 버전을 보류한다. 목록에서 빠졌다는 이유로 삭제나 마감을 추정하지 않는다.
- 농업 관련 키워드 후보는 비공개 검토 상태로만 저장한다. 일반 중소기업 분류를 농업인 신청 자격으로 간주하지 않는다. 다른 기관의 재게시 자료는 기존 검토 기능에서 원문·연도·기간을 함께 대조해야 한다.

## 이용 조건과 보류 범위

포털은 공공누리 제3유형(출처표시·변경금지)을 명시한다. 기업마당 자체 이용 조건도 별도 준수한다. API 사용 승인이 모든 원문·첨부의 변경·재배포 허가는 아니다. 공개 승인은 기존 공식 근거·이용 범위 검토를 통과해야 한다. 원문 전체나 첨부를 외부 LLM에 전송하지 않는다.

KoAT는 기존 공식 사업공고 어댑터를 재사용해 목록 최대 3쪽·상세 최대 6건으로 확장한다. 기관·기업·개인 대상과 기간 경과를 구분하며 자동 공개하지 않는다.

농업e지, 농식품 공공데이터포털, 농식품창업정보망, 스마트팜코리아, 그린대로, 농지은행, 농업정책보험금융원·ASSIST, 농정원은 공식 접근 경로와 재이용 조건을 따로 검토했다. 대기 화면·잘못된 robots 응답·로그인·동적 목록·권한 미확인은 자동수집 허가로 해석하지 않는다. 제한을 우회하는 어댑터는 추가하지 않는다.
