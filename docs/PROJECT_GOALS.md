# 개발 목표·운영 기준

## 현재 목표 (2026-11-10)

운영 중인 챗봇 UI·API와 GitHub 소스의 정합성을 확보한다. 승인된 공개 공고
11건을 대상으로 기존 검색·답변 코드를 보존하며, 3건의 원문 발췌와 8건의
승인 요약을 구분한다. 근거가 부족하면 자격·접수 가능 여부·금액을 확정하지 않는다.

- 지원사업·농업금융·재배기술·맞춤 비교·현재 챗봇 UI를 보존한다.
- 필요한 코드·배포 템플릿·재배포/롤백 절차만 Git에 반영한다.
- 비공개 원문·승인 스냅샷은 외부 비공개 입력으로 제공하고 승인·해시를 검증한다.
- 비밀키·운영 DB·로그·인증서·개인정보·서버 전용 환경값은 추가하지 않는다.
- 이번 작업에서는 AWS 서비스·Nginx·운영 데이터·07:00 KST 수집·인증서를 변경하지 않는다.
- 외부 LLM을 호출하지 않으며 운영 API의 local-only 및 네트워크 격리를 유지한다.
- 관련 핵심 검사 후 검토한 파일만 커밋·Push한다. 다음 개발은 임의로 시작하지 않는다.

현재 구성과 한계, 비공개 자료 복원 및 롤백 절차는
[챗봇 운영 소스 안내](../deploy/chatbot/README.md)를 따른다.

## AI 상담 가독성·대화 개선 (2026-11-12)

- 최신 지시에 따라 블랙 배경·화이트 답변 카드, 지역 탐색, 제한된 인사·감사·도움말, 대화의 지역·관심 작물·경영체 응답과 후속 질문을 구현하고 AWS에 반영한다.
- 승인된 공개 공고만 검색하며 원문 발췌·승인 요약·모집기간 경과·미확인 조건을 구분한다. 신청 자격을 확정하거나 외부 LLM을 호출하지 않는다.
- 기존 운영 중인 승인 자료 60초 갱신 코드를 소스에 보존한다. API 보안·128MiB 제한·수집·DB·승인·공개 피드·인증서 설정은 변경하지 않는다.
- 로컬 집중 검사 28개 및 실제 AWS Chrome 1440px·390px·320px 검사를 통과했다. 배포 전후 DB 99건·승인 124건·공개 11건이 같고, 자동 갱신 진행·API 정상 상태·OOM 0회를 확인했다. 최대 메모리는 35,749,888바이트였다.
- 전주 관련 공고는 면세유 가격안정 지원사업 1건이며 기재 모집기간 경과를 안내한다. 지역 관련성과 신청 자격·접수 가능 여부를 구분한다.
- 대화 상태는 페이지 메모리에서만 유지하고 새 대화·새로고침 시 초기화한다. 제한된 규칙 기반 상담이며 일반 목적 생성형 대화를 제공하지 않는다.

## 홈페이지 지원사업 탐색 진입 (2026-11-12)

- 핵심 디자인은 블랙 배경과 흰색 또는 #F5F5F5 콘텐츠 카드로 유지한다. 히어로의 상담 버튼을 제거하고 스크롤 안내로 두 가지 탐색 카드에 연결한다.
- 화면 순서는 히어로 → 지원사업 탐색 방법 → 기존 3개 서비스 카드 → 푸터다. AI 질문 카드는 채팅 입력창으로 직접 열고, 조건 카드는 기존 지원사업 조건 입력을 사용한다.
- 상담의 중복 방법 선택 화면은 제거하되 대화 기록·맥락·근거 보기·새 대화·흰색 답변 카드를 유지한다. 모션 감소 설정과 키보드 조작을 지원하며 콘텐츠를 애니메이션 대기 상태로 숨기지 않는다.
- 웹 파일 3개만 AWS에 적용한다. 챗봇 API·승인 자료·DB·수집·Nginx·인증서·60초 갱신 설정은 변경하지 않는다. 실패 시 웹 파일만 이전 상태로 복원한다.
