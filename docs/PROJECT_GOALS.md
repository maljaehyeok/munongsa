# 개발 목표·운영 기준

## 최신 목표 — 기존 공고 활용 및 확인된 조건 비교 개선 (2026-11-14)

- 비공개 공고를 출처별로 재분류하고, 공식 페이지의 공공누리 표시와 허용 범위를 확인한 최소 사실정보·원문 링크의 안내를 확대한다. 원문·첨부·미확인 조건은 재배포하지 않는다.
- 공개 공고의 확인된 필수조건 일부를 기존 조건 비교 엔진에 연결하되, 관련 가능성·추가 확인과 전체 신청 자격 확정을 구분한다. 모집기간과 실제 접수 여부, 전국 접수 체계와 개인의 자격 충족을 혼동하지 않는다.
- 중복·변경 안내의 검토 버전을 묶고, 지원사업이 아닌 유상 구매 안내는 제외한다. DB·승인 이력·API·KoAT·GPT·60초 갱신·07:00 수집·HTTPS를 보존하고 이번 범위만 GitHub·AWS에 반영한다.

## 최신 목표 — 공식 안내와 맞춤 추천 기준 분리 (2026-11-14)

- 사용자 지시에 따라 기본 안내는 공식 제목·기관·유효한 공식 링크·출처별 허용 범위를 확인하면 공개한다. 세부 자격·금액 미확인을 기본 안내 비공개 사유로 삼지 않는다.
- 기본 안내 자동 반영과 맞춤 추천 승인을 분리한다. 안내 공고는 자격·모집 여부 미확인을 명시하고, 기존 승인·자격·근거 엔진과 60초 갱신은 엄격하게 유지한다.
- 원문·첨부·새 요약은 재배포하지 않는다. 출처별 정책을 재사용하되 범위 미확인·제한 자료는 보류한다. 기존 DB·승인 이력·07:00 수집·두 API·KoAT·GPT·HTTPS를 보존한다.

## 최신 목표 — 공식 지원사업 수집 확대 1차 (2026-11-12)

- 기존 19곳을 유지하면서 실제 접근·정책·구조가 확인된 전북도 알림 게시판과 농업농촌 공모사업 게시판을 추가한다. 인증 보류 API·접근 제한 기관을 우회하거나 재조사하지 않는다.
- 모집 공고와 시행지침·지원계획을 구분한다. 뉴스·행사·채용·입찰·장비 등은 제외하며, 게시판의 지역만으로 거주지·영농지 요건을 생성하지 않는다.
- 공식 본문의 지역·연령·경력·등록·작물·신청 주체를 근거와 함께 후보로 구조화한다. 과정·대안·특별전형·기준일·미확인 요건은 관리자 검토 전 결합 판정을 보류한다. 미기재 조건은 제한 없음으로 바꾸지 않는다.
- 최초 수집은 새 출처만 제한적으로 실행하고 기존 기록과 승인·공개 14건은 변경하지 않는다. 신규 자료는 비공개 검토 대기로 저장하며 승인 이력을 우회하지 않는다. 실제 본문·스냅샷·운영 DB는 Git에 추가하지 않는다.
- 기존 오전 7시 수집 예약을 유지하고 새 출처를 같은 수집기에 연결한다. 변경 코드·설정만 main·AWS에 반영하며 GPT·챗봇·금융·재배기술·Nginx·인증서는 그대로 보존한다.

## 최신 목표 — 검토 대기 분류·공개 병목 개선 (2026-11-13)

- 기존 검토 명령을 재사용해 신청 후보·시행지침·중복·기재 기간 경과·지원사업 외 자료·원문 확인 필요로 구분한다. 분류는 승인이나 현재 접수 가능 확인이 아니다.
- 저장된 기간은 한국시간 현재 날짜로 다시 계산한다. 공식 링크·기간·대상·자격·지원 내용·신청 방법의 근거 확보와 미확인 사항, 보류 사유를 관리자 검토 결과에 함께 표시한다.
- 공식 원문을 확인한 개별 공고만 기존 명시적 검토·승인·감사·백업 절차로 공개한다. 확인된 기본 사실의 독립 요약과 전체 자격 검증을 구분하고, 거주지와 영농지·세부 연령·지급액을 추정하지 않는다.
- 중복 판정은 공식 게시물 식별자 또는 양쪽 자료 버전에 묶인 원문 대조 근거가 필요하다. 중복·종료·참고 자료도 삭제하지 않는다. 비공개 원문·DB·승인 계획·운영 분류 기록은 Git에 올리지 않는다.
- 21개 출처는 정기 성공·실패·의도적 비활성·신규 실행 미확인을 구분한다. 접근 제한은 우회하지 않으며 GPT·챗봇·금융·재배기술·07:00 수집·TLS 설정을 보존한다.

## 최신 목표 — 상담 안에서 조건 선택·자연어 입력 통합 (2026-11-12)

- 상담에서 선택형 입력과 자유 질문을 함께 제공한다. 기존 거주지·영농지·신청 주체·등록 여부·작물·영농 상태·나이·인원·경력·시설면적의 검증된 대화 상태와 검색·비교 엔진을 재사용한다.
- 선택과 자연어 추출은 같은 임시 상태를 사용한다. 이미 알려준 조건은 채워 두고, 모르는 항목·건너뛰기·부분 입력·조건 수정·새 대화 초기화를 지원한다. 가정 질문은 실제 상태를 바꾸지 않는다.
- 독립 조건 검색을 유지한다. 선택형 검색은 GPT를 다시 호출하지 않고 기존 승인·해시·기간·자격 비교로 처리한다. 공식 기준일·독립경영 인정·전체 자격을 임의 판단하지 않는다.
- 필요한 웹 3개·API 2개 및 관련 검사·소스 목록만 main·AWS에 반영한다. GPT 서비스·60초 갱신·공개 14건·운영 DB·승인·수집·Nginx·인증서는 변경하지 않고, 실패하면 이번 웹·API 변경만 복구한다.

- 기존 UI를 재사용하고 API 코드 3개·웹 파일 2개만 AWS에 반영한다. 60초 갱신·승인/해시 검증·128MiB 제한·네트워크 격리·DB·수집·Nginx·인증서를 보존한다. 외부 LLM은 호출하지 않는다.
