# 상담 응답 개선 기록 — 2026-11-13

- 문제: “안녕, 너는 무슨 역할이 가능하니?”에 기능 안내 대신 공고 질문을 다시 작성하라고 안내했다.
- 원인: 인사는 문장 전체가 정해진 표현과 일치해야 했고, 도움말 표현이 제한적이었다. GPT가 분류한 인사·도움말 의도가 응답 선택에 전달되지 않았다.
- 해결: 기본 인사·서비스 소개·입력 안내·조건 수정은 검증된 로컬 안내를 우선 사용한다. 다른 표현의 검증된 GPT 의도도 같은 안내로 연결하되, 사업별 사실 질문과 새 사용자 조건은 기존 검색·조건 추출로 전달한다.
- 전후: 재질문 요청 → 실제 기능 소개·모르는 항목 건너뛰기·기존 조건 입력창 진입. 이미 입력한 값은 유지하고 누락 항목만 최대 두 개 묻는다.
- 함께 확인한 오류: “지원받을 수 있을까?”의 탐색 누락, “안산에 사는데 전주 사업…”에서 거주지 누락과 명시적인 타지역 탐색의 과도한 제외를 보완했다. 실제 자격 불일치 표시는 유지한다.
- 로컬 검증: 상담 집중 11개·지역 회귀 7개 통과. 인사 7가지 표현, GPT 안내 의도, 모델 미사용 복귀, 조건 보존·수정·가정, 초보 탐색, 후속 마감 질문, 승인 확인 실패 차단을 포함한다.
- 화면 검증: Chrome 1440/390/320px의 수정 작업본을 미리보기로 검사했다. 이는 AWS 배포 완료 증거가 아니다. 실제 배포 결과는 별도의 비공개 실행 결과에 기록한다.
- 사용자 가치: 재질문을 강요받지 않고 서비스 역할과 다음 행동을 이해하며, 기존 조건을 다시 입력하지 않고 상담을 이어갈 수 있다.
- 한계: 범용 생성형 대화가 아니며, 사업 사실은 기존 승인 근거만 사용한다. 실제 농업인 사용성 평가나 일반 GPT 대비 우수성을 이 검사로 입증하지 않는다.
