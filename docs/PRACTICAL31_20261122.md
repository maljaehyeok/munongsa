# 무농사 3.1 신청 준비·금융 연결

## 실제 변경

- 상세 승인 기준은 공개 원본과 비교한다. 화면용 모집 상태·조건 투영 때문에 정상 상세가 숨던 오류를 수정했다. 운영 공개 126건과 상세 19건 기준 표시 가능 상세는 2건에서 12건으로 늘고, 신청 방법 7건·서류 6건을 재사용한다. 나머지 7건은 승인 기준이나 공개 범위가 달라 계속 차단한다. 승인 자료를 갱신하거나 상세 권한을 확대하지 않는다.
- 카드·상세의 기존 공통 판정에 다음 행동을 연결한다. 미확인 조건과 서류 부족을 명시하며 기간 경과 공고의 준비 정보를 현재 신청 안내로 표현하지 않는다.
- 상담의 초보 안내·조건 수정·다음 결과 탐색·금융 후속 신청 안내를 기존 기능에 연결한다. 이미 입력한 조건을 다시 묻지 않으며, 금융 신청 안내는 기존 공식 4개 제도 자료만 사용한다.
- 사업비·보유 자금을 구분하고 선택적으로 차액을 필요 자금에 적용한다. 차액은 단순 산술이며 지원금·대출 승인·중복 수혜 가능액이 아니다. 가정 질문은 실제 금액에 저장하지 않는다.

## 근거 보강과 한계

기존 근거가 있는 파주 공고 3건을 robots 및 기존 안전한 본문 수집기로 재확인했다. 기존 조건 6개를 비공개 재검토 후보로 정리했으며 신규 운영 조건은 0개다. 등록 농지·품목별 면적·추가 신청 범위 등 필수조건을 충분히 표현하지 못하는 부분은 추가 확인으로 유지한다. 근거 문장과 원문 확인 기록은 비공개 작업 자료에 보관한다.

지역 미확인 공고를 전국 사업으로 확정하지 않는다. 일부 조건 일치도 전체 신청 자격 충족으로 표현하지 않는다. 공식 기간과 실제 접수는 구분한다. 신규 승인·운영 DB 변경·미승인 39항목 적용은 이번 범위에 없다.

## 검증 및 배포 계약

김제·토마토·미등록·자금 수요 사례와 등록 농업인·타지역·복합 상담·정보 부족·일반 대화 사례를 격리된 후보 및 실제 운영 브라우저에서 구분해 검사한다. 화면 규격은 1440·390·320px다. 가상 사례 검사이며 농업인 설문 결과가 아니다.

서버 전용 웹 변경을 보존한 후보만 배포한다. 서버 상세 SDK의 승인 게이트와 필드 계약은 보존하고 렌더링 함수만 변경한다. 공개 JSON·상세 JSON·전체 DB 테이블·승인 이력·비밀 설정·수집 일정의 해시를 전후 대조한다. SQLite 공식 백업과 별도 복원본 무결성을 검사하고 장애 시 코드만 롤백한다.
