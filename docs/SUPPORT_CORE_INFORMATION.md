## 적용 범위

기존 상세정보 19건의 공식 자료를 검토하고 18건의 본문을 읽었다. 접근 정책을 확인하지 못한 OADS 자료는 제외했다. 이 중 신청 준비 정보가 명시된 11건을 **로컬 검토 초안**으로 구조화했다. 추가 8건은 본문 8건을 확인했고 7건을 초안에 포함했다. 나머지 고창 AI 마케팅 교육은 이번 지원사업 보완의 우선 대상에서 제외했다.

기존 공개용 `assets/support-details.json` 11건과 승인·해시 정책은 변경하지 않았다. 원문, 발췌, 계획 파일, 검토 피드는 Git에서 제외되는 `work/core-information-20261117/`에만 보관한다. 기존 링크 검증 90건은 과거 이력으로 참고했으며 현재 접근성 90건을 재검증한 결과가 아니다.

## 로컬 확인 및 승인 경계

저장소 루트에서 로컬 정적 서버를 실행하고 `http://127.0.0.1:포트/?support-details-preview=1`로 접속한다. 별도로 생성한 `work/core-information-20261117/review-final/preview-details.json`과 `preview-feed.json`이 필요하다. 기본 접속과 운영 도메인에서는 초안을 불러오지 않는다. 원문·비공개 자료가 있는 개발 서버는 외부에 공개하지 않는다.

피드의 표시 허용 필드는 기존 화면 계약에 맞춘 로컬 렌더링용이다. 실제 공개 허가나 관리자 승인이 아니다. `local_review_only` 피드는 상담 검색에서 거부되고, 상세 자료의 `preview` 상태도 기존 승인 근거 검색에서 거부된다. 실제 운영 승인 DB가 없어 새로운 조건을 추천 판정에 반영하지 않았다.

공개 반영 전에는 기존 검토 도구의 정확한 계획 해시 승인, 현재 운영 승인·공개 상태 대조, 출처별 표시 범위 확인이 필요하다. 본문·첨부·운영 DB·키를 저장소에 넣지 않는다.

## 화면 및 검증 결과

- 상세 정보를 신청기간, 대상, 지원 내용, 금액·자부담, 방법·접수처, 서류, 문의·주의사항 순서로 배치했다. 없는 핵심 항목은 확인되지 않았다고 표시한다.
- 일반 제출서류 목록과 명시적인 필수 서류를 구분한다. 접수처를 거주지·영농지 자격으로 바꾸거나 사업 운영기간을 신청기간으로 바꾸지 않는다.
- 동일한 선정 11건 기준 기존 상세자료와 새 초안의 항목 수: 대상 4→11, 기간 4→11, 명시 금액·한도 4→3, 신청 방법 4→8, 접수처 4→8, 서류 4→7, 문의 전화 4→11. 대상·기간의 기존 수는 기존 기본 정보도 포함한다. 금액은 새로 읽은 본문의 명시 항목만 집계했으며 기존 승인 금액을 삭제한 것이 아니다. 이 수치는 전체 운영 공고 통계가 아니다.
- 실제 접수 완료 검증 0건, 독립된 신청 페이지 검증 0건이다. 신청 버튼이나 로그인 안내를 접수 성공으로 간주하지 않는다. 포항 연령 표현 충돌과 첨부 지침 전체 조건은 미확인으로 남겼다.
- 관련 Python 52개, JavaScript 미리보기·이스케이프 검사 7개를 통과했다. Chrome 로컬 화면 1440·390·320px에서 11개 카드와 상세 7구역을 열고 가로 넘침이 없음을 확인했다. 원문 링크는 HTTPS로 제공하며 외부 LLM 호출은 하지 않았다.
- AWS·운영 DB·승인·자동수집·인증서는 변경하지 않았다. 실제 GPT 응답과 운영 승인 근거의 통합 검증은 미실시다.
