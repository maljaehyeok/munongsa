# 전국 공고 실사용 확대

- 신규 검토 48건을 기존 운영 ID와 대조했다. 기업마당 45건의 공식 상세 제목·대상·기간을 확인했으며 API와의 핵심정보 충돌은 없었다. 해당 상세페이지가 별도 지자체 원공고나 실제 접수 완료를 대신하지 않는다.
- 기본 안내 승인 준비 43건, 보류 4건(동일 제목·다른 ID 2건, 게시판 이용범위 확인 2건), 이용자 대상에서 제외 1건(창업지원 주관기관 모집)이다. 공개 범위는 제목·기관·공식 링크로 제한하며 모두 미승인이다.
- 기존 공개 83건 중 전주·산청·함안 3건의 명시 지역 문장을 공식 페이지에서 재대조했다. 산청 주소지·농지를 결합 요건으로 보존하고, 함안 피해요건을 생략하지 않는다. 후보이며 운영 승인과 별개다.
- 원래 8조건은 부분 승인 권장 5개, 추가 확인 1개, 제외 권장 2개로 정리했다. 구례·삼척 수출업체를 개인 농업인 전용으로 좁히는 추출을 차단한다. 홍천의 관내 범위는 추측하지 않는다.
- 성별·출생연도, 등록농지·생산, 추가·변경 신청, 복수 신청 주체는 미확인 필수조건으로 보존한다. 독립적인 지역 문장만 후보로 추출하며 예외·이전·타 시군 분기는 자동 단일화하지 않는다.
- 기존 승인·공개·GPT 검증 경로는 유지한다. 새 자료를 승인된 상담 근거로 자동 편입하지 않으며 미승인 상세 보완 39항목도 적용하지 않는다.
- 이번 코드 변경은 향후 비공개 추출 오류를 줄인다. 신규 공개와 검증된 운영 추천 증가량은 모두 0이다. 승인 전 사용자에게 미확인 자격을 확정할 수 없다.
- 공고별 근거·이용범위·제외항목·최종 승인 범위는 비공개 작업 자료 `work/usability-evidence-20261122/FINAL_APPROVAL.md`에 통합한다. 원문·첨부·개인 연락처는 Git에 포함하지 않는다.
