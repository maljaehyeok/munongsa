## 프로젝트 소개

농업 지원사업 정보는 기관·지역별로 분산되어 있고 신청 대상과 모집기간도 다릅니다. 무농사는 사용자의 영농 상황에 관련된 지원사업을 탐색하고, 농업금융 제도와 공식 재배기술 자료까지 한곳에서 살펴볼 수 있도록 만든 **중간발표용 MVP**입니다.

공식 출처와 확인 가능한 조건을 우선 안내합니다. **맞춤 비교 결과는 신청 자격의 확정 판정이 아니며**, 공고의 실제 접수 가능 여부·금융 승인·재배기술의 개별 적용 가능성을 보장하지 않습니다.

## 도메인·HTTPS·검색엔진 설정 (2026-10-31)

- **DNS:** DuckDNS 서브도메인 `munongsa.duckdns.org`를 AWS 서버 `43.201.72.109`에 연결했습니다. 별도 유료 도메인은 구매하지 않았습니다.
- **HTTPS:** 신규 도메인과 기존 IP 주소 모두 TLS 접속을 유지합니다. 도메인 인증서 만료 예정은 **2027-01-29 15:34:33 KST**이며, 하루 2회 자동 갱신 확인과 모의시험 통과가 보고되었습니다. **실제 향후 갱신 성공은 아직 확인된 사실이 아닙니다.**
- **기존 IP 인증서:** 별도 인증서·갱신 설정 유지. 과거 보고된 만료 예정일은 **2026-11-07 06:00:12 KST**, 갱신 확인 주기는 6시간입니다. 실제 갱신 성공과 공인 IP 고정 여부는 추후 확인 대상입니다.
- **SEO:** `canonical`, `sitemap.xml`, `robots.txt`의 대표 주소를 신규 도메인으로 통일했습니다. 기존 IP를 새 도메인으로 자동 리디렉션하지는 않습니다.
- **네이버 서치어드바이저:** 신규 도메인 소유확인, 사이트맵 제출, 홈페이지 수집 요청을 완료했습니다.
- **Google Search Console:** 신규 도메인 소유확인 및 사이트맵 제출을 진행했습니다. 실시간 URL 검사에서 크롤링 허용·페이지 가져오기 성공·색인 허용으로 표시되었지만, **사이트맵 처리 상태는 '가져올 수 없음'**으로 나타났습니다. 기존 IP 속성에서도 동일한 상태가 관찰됐습니다. 정확한 원인은 확인되지 않았으며 실제 검색 노출은 미확인입니다.
- 검색엔진 **소유확인·사이트맵 제출·수집 요청은 실제 색인 생성이나 검색 노출을 보장하지 않습니다.**

## 로컬 실행

### 정적 웹사이트

VS Code의 Live Server 또는 다른 로컬 HTTP 서버로 `index.html`을 제공합니다. `file://`로 직접 열면 `fetch()`를 통한 JSON 로드가 제한될 수 있습니다.

### Docker

```bash
docker build -t munongsa:local .
docker run --rm -d --name munongsa -p 127.0.0.1:8080:80 munongsa:local
```

`http://localhost:8080`에서 확인하고, 종료할 때 `docker stop munongsa`를 실행합니다. 이 명령은 **로컬 정적 화면 검사용**이며 실제 AWS의 인증서·프록시·자동수집 구성을 재현하지 않습니다.

### 별도 Flask 시연 앱

```bash
python -m pip install Flask
python app.py
```

`app.py`는 정적 무농사 웹서비스와 별개의 시연 앱입니다. 개발용 `debug=True` 설정을 공개 운영에 사용하지 않습니다.
