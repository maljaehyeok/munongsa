# 🌱 무농사 (MUNONGSA)

**초보·청년 농업인을 위한 맞춤형 농업정보 탐색 웹서비스**

전북대학교 스마트팜학과 · 스마트팜창의설계 캡스톤디자인 (2026)

**[웹서비스 이용하기](https://munongsa.duckdns.org/)**

## 프로젝트 소개

농업을 처음 시작하는 사람은 지원사업, 금융 제도, 재배기술 정보를 여러 기관에서 따로 찾아야 합니다. 공고를 발견하더라도 자신의 영농 상황에 맞는지, 언제 신청할 수 있는지 판단하기 쉽지 않습니다.

**무농사(MUNONGSA)**는 사용자의 영농 상황을 바탕으로 관련 농업 지원사업을 탐색·비교하고, 농업금융 제도와 공식 재배기술 자료까지 연결하는 웹서비스입니다.

단순히 정보를 모으는 데 그치지 않고, **왜 관련 있는 정보인지, 무엇을 추가로 확인해야 하는지, 어디에서 공식 정보를 확인할 수 있는지** 안내하는 것을 목표로 합니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| **지원사업 탐색** | 사업명·지역·작물 등으로 검색하고 모집상태, D-day, 지원 내용, 신청처와 공식 공고를 확인 |
| **맞춤형 조건 비교** | 입력한 영농 상황과 공고의 확인 가능한 조건을 비교하여 일치·불일치·추가 확인 필요 구분 |
| **농업금융 안내** | 후계농 육성자금, 귀농 창업·주택자금, 농지매매 지원, 농신보 등 대표 4개 제도의 조건·공식 출처 탐색 |
| **재배기술 탐색** | 67종 작물·8개 분류를 바탕으로 주제별 공식 재배자료 탐색; 12종 작물은 관련 자료 직접 연결 |
| **반응형 웹 UI** | PC·모바일 화면, 검색·필터, 선택 조건 표시, 상세정보 및 공식 링크 제공 |

### 정보 제공 방식

- 지원사업 정보는 공식 출처를 우선 활용하며, **자동수집 → 검토 → 승인 후 공개** 절차로 관리합니다.
- 매일 오전 7시(KST) 자동수집을 예약하고 신규·변경 자료를 확인합니다. 정보원별 수집 성공 여부와 공개 자료의 최신성은 별개입니다.
- 맞춤 비교는 **확인 가능한 조건에 대한 안내**이며, 개인별 최종 신청 자격을 확정하지 않습니다.
- 모집기간이 남아 있어도 실제 접수 여부는 달라질 수 있습니다. 금융 조건과 재배기술도 공식 원문 및 개별 상황을 확인해야 합니다.

## 기술 스택 및 서비스 구성

| 구분 | 기술·구성 |
| --- | --- |
| 프런트엔드 | HTML, CSS, JavaScript |
| 웹서비스 제공 | Docker, Nginx |
| 인프라 | AWS EC2 (Ubuntu) |
| 데이터 | JSON 기반 웹 화면 데이터, 별도 운영 DB·수집·검토 체계 |
| 도메인·보안 연결 | DuckDNS, HTTPS(TLS) |
| 버전 관리 | Git, GitHub |

웹 화면은 정적 리소스와 JSON 데이터를 읽어 동작합니다. 운영 서버에서는 별도로 자동수집·검토·승인 및 상태 저장 작업을 수행합니다. **저장소의 정적 Docker 이미지만으로 전체 운영환경이 재현되는 것은 아닙니다.**

## 프로젝트 구조

```text
.
├── index.html          # 메인 웹페이지
├── assets/             # UI 및 탐색·조건 비교 기능
├── data/               # 지원사업·금융·재배기술 관련 JSON
├── scripts/            # 데이터 관리 스크립트
├── Dockerfile          # 정적 웹서비스용 Nginx 이미지
├── robots.txt          # 검색엔진 크롤링 안내
├── sitemap.xml         # 사이트맵
├── app.py              # 별도 Flask 시연 앱
└── README.md
```

## 로컬 실행

### Docker

Docker가 설치된 환경에서 프로젝트 루트에서 실행합니다.

```bash
docker build -t munongsa:local .
docker run --rm -d --name munongsa -p 127.0.0.1:8080:80 munongsa:local
```

브라우저에서 **http://localhost:8080**으로 접속합니다. 종료할 때는 `docker stop munongsa`를 실행합니다.

Docker 없이 확인하려면 VS Code Live Server 등 **로컬 HTTP 서버**로 `index.html`을 제공할 수 있습니다. `file://`로 직접 열면 JSON 로딩이 제한될 수 있습니다.

`app.py`는 정적 웹사이트와 별개의 Flask 시연 앱이며, 위 Docker 실행에 포함되지 않습니다.

- 공식 자료 자동수집과 검토·승인 후 공개 체계
- PC·모바일 대응 및 영농 조건별 비교 기능

본 프로젝트는 **2026년 11월 2일 중간발표, 12월 7일 최종발표**를 목표로 진행 중입니다.

> **이용 안내:** 무농사는 공식 기관의 신청·심사·진단을 대신하지 않습니다. 지원사업의 최종 신청 자격·접수 상태, 금융 승인 조건, 재배기술 적용 가능성은 반드시 연결된 공식 자료와 담당 기관을 통해 확인해야 합니다.
