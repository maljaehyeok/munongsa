# 무농사

## 프로젝트 소개

무농사는 초보 농업인이 농업 지원사업, 작물 재배 정보, 스마트농업 관련 정보를 자신의 조건에 맞게 찾아볼 수 있도록 돕는 웹서비스를 목표로 합니다.

현재 개발 및 데이터 검증 중인 프로젝트입니다. 카탈로그에 포함된 모든 정보가 검증 완료된 것은 아니며, 실제 신청·구매·영농 의사결정 전에는 반드시 해당 기관의 최신 공식 자료와 담당 기관 안내를 확인해야 합니다.

## 프로젝트 구조

```text
.
├── index.html                              # 정적 웹사이트 화면
├── index-before-redesign.html              # 이전 화면 보존본
├── app.py                                  # 별도로 구현된 Flask 시연 앱
└── data/
    ├── smart-agriculture-catalog.json      # 웹사이트가 사용하는 카탈로그 데이터
    └── source/                              # 조사 및 데이터 수집 자료
```

`outputs/`에는 결과물이, `work/`에는 작업용 자료가 있습니다. 이 폴더의 파일이 모두 저장소에 포함되는 것은 아닙니다. 업로드 전에 각 파일의 필요성, 개인정보 포함 여부, 재배포 조건을 확인하세요.

## 정적 웹사이트 실행

1. 프로젝트 폴더를 Visual Studio Code에서 엽니다.
2. Live Server 확장 기능을 설치한 뒤 `index.html`을 엽니다.
3. 편집기에서 **Open with Live Server**를 선택합니다.

페이지는 `data/smart-agriculture-catalog.json`을 `fetch()`로 읽습니다. 브라우저에서 HTML을 `file://` 방식으로 직접 여는 경우 JSON 접근이 제한될 수 있으므로 로컬 HTTP 서버로 실행하는 것을 권장합니다.

## Flask 시연 앱 실행

Python과 Flask가 필요합니다. 이 저장소는 현재 Python 또는 Flask의 특정 버전을 확정된 요구사항으로 지정하지 않습니다. 설치 명령은 다음과 같습니다.

```bash
python -m pip install Flask
python app.py
```

`app.py`는 자체 데이터와 화면을 사용하는 별도의 Flask 시연 앱입니다. `index.html`과 `data/smart-agriculture-catalog.json`을 실행하는 서버가 아니며, 두 실행 방식은 서로 별개입니다.

`app.py`의 `debug=True` 설정은 로컬 개발 전용입니다. 공개 서비스나 배포 환경에서 개발 서버와 디버그 모드를 사용하지 마세요.

## 데이터 검증 원칙

- 공식 출처 URL, 자료 게시일 및 확인일, 근거 위치를 확인합니다.
- 사업 상태와 신청 기간을 최신 공식 공고에서 확인합니다. 모집 여부가 불확실하면 모집 중으로 표시하지 않습니다.
- 자료가 존재한다는 사실만으로 신청 자격이나 지원 가능 여부를 확정하지 않습니다.
- 팀 아이디어와 후보 제품은 검증된 판매 제품이나 공식 지원 품목과 구분합니다.
- 데이터 검증이 완료되지 않은 항목이 포함될 수 있으므로, 신청·구매·재배에 적용하기 전에 원문과 담당 기관을 확인합니다.

## 개인정보와 공개 주의사항

- 개인 연락처, 비밀번호, API 키, 토큰, 로컬 절대 경로가 포함된 파일을 공개 저장소에 올리지 마세요.
- 조사 자료와 문서의 재배포 조건 및 이용허락을 확인한 뒤 업로드하세요.
- `.gitignore`는 지정된 파일 패턴을 Git에서 제외하도록 도울 뿐, 모든 민감정보를 자동으로 탐지하거나 제거하지 않습니다. 업로드 전에 파일 내용과 변경 목록을 직접 확인해야 합니다.

## 프로젝트 상태와 저장소 운영

프로젝트는 현재 개발 및 데이터 검증 단계입니다. GitHub 저장소는 비공개로 운영하는 것을 권장합니다. 데이터 출처, 확인일, 근거 위치, 검증 상태와 신청 상태를 지속적으로 관리할 계획입니다.
