# 🌱 무농사 (MUNONGSA)

**초보·청년 농업인을 위한 맞춤형 농업정보 탐색 웹서비스**

전북대학교 스마트팜학과 · **2026 스마트팜창의설계 캡스톤디자인**

**[🌐 무농사 웹서비스 바로가기](https://munongsa.duckdns.org/)**

## 1. 프로젝트 소개

농업을 처음 시작하는 사람은 지원사업, 농업금융, 재배기술 정보를 여러 기관에서 따로 찾아야 합니다.   
공고를 찾더라도 자신의 영농 상황에 적합한지, 신청 시기는 언제인지, 어떤 조건을 추가로 확인해야 하는지 파악하기 어렵습니다.

무농사(MUNONGSA)는 흩어진 농업정보를 사용자의 관점에서 연결하는 웹서비스입니다.   
사용자는 영농 상황을 바탕으로 관련 지원사업을 탐색하고, 농업금융 제도를 비교하며, 작물별 공식 재배기술 자료를 찾을 수 있습니다.

> **서비스 목표:** 사용자가 자신에게 필요한 농업정보를 쉽게 발견하고, 확인해야 할 조건을 이해하며, 공식 신청처·자료까지 연결될 수 있도록 돕는 것.

무농사는 공식 기관을 대신해 신청 자격이나 재배 문제를 확정 판단하지 않습니다.   
**공식 근거와 추가 확인이 필요한 부분을 함께 안내하는 탐색·비교 서비스**를 지향합니다.

## 2. 핵심 서비스

### ① 지원사업 — 내 상황에 관련된 농업 지원사업 찾기

여러 기관의 농업 지원사업을 한곳에서 탐색하고, 사용자 조건과 공고의 확인 가능한 자격요건을 비교할 수 있습니다.

- **공고 검색·필터:** 사업명, 지역, 작물, 모집상태 등을 기준으로 탐색
- **모집 일정 확인:** 모집 예정·모집 중·마감 임박·종료·미확인 등 상태와 D-day 표시
- **지원 내용 확인:** 지원 대상, 주요 지원 내용, 신청기간, 신청처 및 공식 원문 링크 제공
- **영농 상황별 맞춤 비교:** 사용자가 입력한 조건과 공고의 명시된 조건을 비교
- **비교 결과 구분:** 확인된 조건에 대한 일치·불일치·추가 확인 필요 표시

**2026년 11월 최종 발표 기준:** 공개 공고 126건 중 26건에 대해 승인된 **일부 자격조건**을 비교할 수 있습니다. 신청 준비 안내는 35건에 연결되어 있지만, 그중 상세 준비정보가 연결된 공고는 7건입니다.

**맞춤 비교는 신청 자격을 확정하는 심사 결과가 아닙니다.**   
일부 공고 조건은 자동 판정할 수 없으며, 실제 신청 가능 여부는 공식 공고를 통해 확인해야 합니다.

### ② 농업금융 — 농업에 필요한 자금 제도 알아보기

농업을 준비하거나 운영할 때 참고할 수 있는 대표적인 금융·지원 제도를 탐색합니다.

- 후계농 육성자금
- 귀농 창업·주택자금
- 농지매매 지원
- 농신보(농림수산업자신용보증기금)

제도별 대상, 자금 용도, 한도 등 확인 가능한 조건을 비교하고 공식 안내 자료로 연결합니다. 일부 제도에는 명시된 가정에 따른 **단순 이자 계산**을 제공합니다. 이는 실제 월 상환액이나 대출 심사 결과가 아닙니다.   
자금 목적 및 필요한 금액을 활용한 탐색 기능을 제공합니다.

**융자·보증·농지 지원은 서로 다른 제도**이며, 화면에 표시된 한도가 개인별 승인 금액을 의미하지는 않습니다.

### ③ 재배기술 — 작물별 공식 재배정보 찾기

관심 작물을 선택하고 재배 단계·주제에 관련된 공식 농업기술 자료를 찾아볼 수 있습니다.

- **67종 작물·8개 분류**의 서비스용 탐색 목록(처음 8종 표시, 검색·별칭·전체 보기) 활용
- 재배 시작, 환경 관리, 물·비료, 병해충, 수확 등 주제별 자료 탐색
- 작물·주제별로 공식 자료 연결 범위가 다르며, 일부 자료는 외부 사이트에서 추가 선택 필요
- **농사로·국가농작물병해충관리시스템·농약안전정보시스템·흙토람** 등 공식 정보원으로 연결

무농사는 출처가 확인되지 않은 개별 재배 처방을 확정적으로 제시하기보다, 사용자가 신뢰할 수 있는 자료를 찾아가도록 돕습니다.

### ④ AI 상담 — 농업정보 탐색과 후속 질문 연결

농업 관련 자연어 질문을 이해해 **지원사업·농업금융·재배기술의 기존 기능**으로 연결합니다.

- **지원사업 상담:** 지역·작물·영농 목적에 따라 관련 공고를 탐색하고, 공식적으로 확인된 자격조건과 미확인 사항을 구분
- **연속 대화:** “그 사업은?”, “10개 추천해 줘”, “전북 전체로 넓혀줘” 등의 후속 요청에서 기존 검색 맥락 유지
- **조건 보호:** 재배 방법 질문·관심·계획·가정과 실제 영농 사실을 구분하고, 조건 변경 결과를 반영
- **농업금융·재배기술 연결:** 기존 금융자료 및 작물·병해충·농약 등 공식 재배정보 메뉴로 이동
- **개념 설명:** 윤작·융자 등 기본적인 농업 용어를 쉽게 설명하되 개별 사업의 공식 자격판정은 기존 승인 근거로 제한

상담은 **규칙 기반 처리와 제한적인 OpenAI API 질문 해석·일반 개념 설명**을 함께 사용합니다. 무관한 잡담에는 원칙적으로 외부 GPT 호출을 사용하지 않으며, 응답 실패 시 재질문 가능한 안내로 복구합니다. 챗봇이 개별 농가의 신청 자격·대출 승인·농약 사용 가능 여부를 확정하지는 않습니다.

## 3. 사용자 경험

네 가지 핵심 서비스는 **처음 농업을 접하는 사람도 이해하기 쉬운 탐색 경험**을 목표로 구성했습니다.

- **간단한 영농 상황 입력:** 지역·작물·신청자 유형 등 관련 조건 선택
- **결과 중심의 화면:** 공고의 핵심 내용, 모집 일정, 공식 링크를 우선 표시
- **PC·모바일 대응:** 화면 크기에 맞춘 반응형 UI
- **조건 확인 및 변경:** 현재 선택한 검색·비교 조건을 확인하고 조정
- **메뉴 간 연계:** 지원사업 상담에서 금융 비교·재배기술 자료로 이동하며 관련 영농 조건 유지
- **검색 범위와 실제 지역 구분:** 익산→전북→전국으로 탐색 범위를 넓혀도 실제 영농지역을 임의 변경하지 않음

예를 들어 전북에서 토마토 재배를 준비하는 사용자는 관련 지원사업을 검색하고, 자신의 조건과 공고를 비교한 뒤, 자금 제도와 토마토 재배자료까지 이어서 살펴볼 수 있습니다.

## 4. 데이터 수집 및 정보 신뢰성

무농사는 공식 기관 자료를 우선 활용하고, 수집한 정보를 곧바로 공개하지 않는 **검토·승인 기반 운영 방식**을 적용합니다.

```text
공식 정보원
    ↓
자동수집 (매일 07:00 KST 예약)
    ↓
신규·변경 정보 탐지 및 저장
    ↓
원문·조건 검토 및 공개 승인
    ↓
사용자 화면에 정보 제공
```

- HTML·RSS 등 이용 가능한 방식으로 정보를 수집합니다.
- 신규·변경 데이터를 관리하고 검토 후 공개합니다.
- 공고별 원문 링크와 확인 가능한 조건을 우선 제공합니다.
- 확인되지 않은 자격조건은 임의로 충족·불충족 처리하지 않습니다.
- 수집이 정상 실행되더라도 일부 정보원의 접근 제한·페이지 변경으로 자료가 누락될 수 있습니다.

**데이터 최신성 안내:** 모집기간 표시와 실제 접수 가능 여부는 다를 수 있습니다. 공식 공고가 최종 기준이며, 모든 공개 정보가 완전히 검증되었다는 의미는 아닙니다.

**서비스 구조**

```text
사용자 브라우저
      │
      ▼
https://munongsa.duckdns.org
      │
      ▼
AWS EC2 / Nginx / Docker
      │
      ├── 웹 화면 (HTML·CSS·JavaScript)
      ├── 상담 API (Python·승인 근거 검색)

                  ▲

                  ▲
                  │
```

웹 화면과 운영 데이터 수집·검토는 구분되어 있습니다.   
**저장소의 Docker 이미지만 실행한다고 AWS의 운영 DB, 예약 수집, HTTPS 인증서 설정까지 자동으로 복원되는 것은 아닙니다.**

위 구조는 **전체 파일 목록이 아닌 대표 파일 안내**입니다.

## 7. 로컬 실행

### Docker로 정적 웹서비스 실행

프로젝트 루트에서 다음 명령을 실행합니다.

```bash
docker build -t munongsa:local .
docker run --rm -d --name munongsa -p 127.0.0.1:8080:80 munongsa:local
```

브라우저에서 **http://localhost:8080**에 접속합니다.

```bash
docker stop munongsa
```

Docker 없이 확인하려면 VS Code Live Server 등 로컬 HTTP 서버로 `index.html`을 제공할 수 있습니다.   
`file://`로 직접 열면 JSON 파일 로딩이 제한될 수 있습니다.

`app.py`는 별도의 Flask 시연 앱으로, 위 Docker 정적 웹서비스에 포함되지 않습니다.

| 운영 | 매일 **07:00 KST** 수집 예약 · 주기적 갱신 · 승인 자료와 내부 검토자료 구분 |
| 배포 | AWS EC2 · Docker/Nginx · HTTPS · PC/모바일 반응형 |

**검증 범위:** 실제 HTTPS 상담과 주요 메뉴의 연속 사용 흐름, 대표 모바일 화면을 기술적으로 점검했습니다. 일반 농업 개념에 대한 실제 GPT 대표 질의 10건은 성공했으며, 발견된 주요 상담·검색 맥락·공개 데이터 전송 오류를 수정했습니다. **실제 농업인 대상 사용성 평가는 아직 수행하지 않았습니다.**

**자료의 한계:** 공개 공고 126건 모두에 대해 공식 자격을 완전 판정하는 것은 아닙니다. 자격 비교 26건은 일부 승인 조건의 비교이며, 신청 준비 연결 35건이 모두 상세 서류·접수처를 완비했다는 뜻도 아닙니다. 공고에 적힌 모집기간과 실제 접수 가능 여부는 다를 수 있습니다. 일부 정보원은 접근 정책으로 자동수집이 제한됩니다.

**배포 구성 안내:** 루트 Docker 이미지만 실행해도 실제 운영 챗봇 API·비공개 승인 근거·운영 DB·예약 수집 환경이 자동으로 재현되지는 않습니다. 별도의 운영 구성이 필요합니다. 상세 운영 절차는 [챗봇 배포 안내](deploy/chatbot/README.md) 및 [수집기 운영 안내](deploy/collector/README.md)를 참고하세요.
