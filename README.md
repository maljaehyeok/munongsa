# 🌱 무농사 (MUNONGSA)

**초보·청년 농업인을 위한 맞춤형 농업정보 탐색 웹서비스**

전북대학교 스마트팜학과 · **2026 스마트팜창의설계 캡스톤디자인**

**[🌐 무농사 웹서비스 바로가기](https://munongsa.duckdns.org/)**

## 1. 프로젝트 소개

농업을 처음 시작하는 사람은 지원사업, 농업금융, 재배기술 정보를 여러 기관에서 따로 찾아야 합니다. 공고를 찾더라도 자신의 영농 상황에 적합한지, 신청 시기는 언제인지, 어떤 조건을 추가로 확인해야 하는지 파악하기 어렵습니다.

무농사(MUNONGSA)는 흩어진 농업정보를 사용자의 관점에서 연결하는 웹서비스입니다. 사용자는 영농 상황을 바탕으로 관련 지원사업을 탐색하고, 농업금융 제도를 비교하며, 작물별 공식 재배기술 자료를 찾을 수 있습니다.

> **서비스 목표:** 사용자가 자신에게 필요한 농업정보를 쉽게 발견하고, 확인해야 할 조건을 이해하며, 공식 신청처·자료까지 연결될 수 있도록 돕는 것.

무농사는 공식 기관을 대신해 신청 자격이나 재배 문제를 확정 판단하지 않습니다. **공식 근거와 추가 확인이 필요한 부분을 함께 안내하는 탐색·비교 서비스**를 지향합니다.

## 2. 핵심 서비스

### ① 지원사업 — 내 상황에 관련된 농업 지원사업 찾기

여러 기관의 농업 지원사업을 한곳에서 탐색하고, 사용자 조건과 공고의 확인 가능한 자격요건을 비교할 수 있습니다.

- **공고 검색·필터:** 사업명, 지역, 작물, 모집상태 등을 기준으로 탐색
- **모집 일정 확인:** 모집 예정·모집 중·마감 임박·종료·미확인 등 상태와 D-day 표시
- **지원 내용 확인:** 지원 대상, 주요 지원 내용, 신청기간, 신청처 및 공식 원문 링크 제공
- **영농 상황별 맞춤 비교:** 사용자가 입력한 조건과 공고의 명시된 조건을 비교
- **비교 결과 구분:** 확인된 조건에 대한 일치·불일치·추가 확인 필요 표시

**맞춤 비교는 신청 자격을 확정하는 심사 결과가 아닙니다.** 일부 공고 조건은 자동 판정할 수 없으며, 실제 신청 가능 여부는 공식 공고를 통해 확인해야 합니다.

### ② 농업금융 — 농업에 필요한 자금 제도 알아보기

농업을 준비하거나 운영할 때 참고할 수 있는 대표적인 금융·지원 제도를 탐색합니다.

- 후계농 육성자금
- 귀농 창업·주택자금
- 농지매매 지원
- 농신보(농림수산업자신용보증기금)

제도별 대상, 자금 용도, 한도 등 확인 가능한 조건을 비교하고 공식 안내 자료로 연결합니다. 자금 목적 및 필요한 금액을 활용한 탐색 기능을 제공합니다.

**융자·보증·농지 지원은 서로 다른 제도**이며, 화면에 표시된 한도가 개인별 승인 금액을 의미하지는 않습니다.

### ③ 재배기술 — 작물별 공식 재배정보 찾기

관심 작물을 선택하고 재배 단계·주제에 관련된 공식 농업기술 자료를 찾아볼 수 있습니다.

- **67종 작물·8개 분류**를 바탕으로 작물 탐색
- 재배 시작, 환경 관리, 물·비료, 병해충, 수확 등 주제별 자료 탐색
- **12종 작물**에 대해 관련 공식 자료로 직접 연결
- 농사로 등 공식 농업정보 제공기관의 자료 활용

무농사는 출처가 확인되지 않은 개별 재배 처방을 확정적으로 제시하기보다, 사용자가 신뢰할 수 있는 자료를 찾아가도록 돕습니다.

## 3. 사용자 경험

세 가지 핵심 서비스는 **처음 농업을 접하는 사람도 이해하기 쉬운 탐색 경험**을 목표로 구성했습니다.

- **간단한 영농 상황 입력:** 지역·작물·신청자 유형 등 관련 조건 선택
- **결과 중심의 화면:** 공고의 핵심 내용, 모집 일정, 공식 링크를 우선 표시
- **PC·모바일 대응:** 화면 크기에 맞춘 반응형 UI
- **조건 확인 및 변경:** 현재 선택한 검색·비교 조건을 확인하고 조정

예를 들어 전북에서 토마토 재배를 준비하는 사용자는 관련 지원사업을 검색하고, 자신의 조건과 공고를 비교한 뒤, 자금 제도와 토마토 재배자료까지 이어서 살펴볼 수 있습니다.

## 4. 데이터 수집 및 정보 신뢰성

무농사는 공식 기관 자료를 우선 활용하고, 수집한 정보를 곧바로 공개하지 않는 **검토·승인 기반 운영 방식**을 적용합니다.

```text
공식 정보원
    ↓
자동수집 (매일 07:00 KST 예약)
    ↓
신규·변경 정보 탐지 및 저장
    ↓
원문·조건 검토 및 공개 승인
    ↓
사용자 화면에 정보 제공
```

- HTML·RSS 등 이용 가능한 방식으로 정보를 수집합니다.
- 신규·변경 데이터를 관리하고 검토 후 공개합니다.
- 공고별 원문 링크와 확인 가능한 조건을 우선 제공합니다.
- 확인되지 않은 자격조건은 임의로 충족·불충족 처리하지 않습니다.
- 수집이 정상 실행되더라도 일부 정보원의 접근 제한·페이지 변경으로 자료가 누락될 수 있습니다.

**데이터 최신성 안내:** 모집기간 표시와 실제 접수 가능 여부는 다를 수 있습니다. 공식 공고가 최종 기준이며, 모든 공개 정보가 완전히 검증되었다는 의미는 아닙니다.

## 5. 기술 스택 및 아키텍처

| 구분 | 기술 및 구성 |
| --- | --- |
| 프런트엔드 | HTML, CSS, JavaScript |
| 웹 콘텐츠 | 정적 리소스 및 JSON 데이터 |
| 데이터 수집·처리 | Python 스크립트, 출처별 수집·검토 로직 |
| 운영 데이터 | 별도 서버 운영 DB, 검토·승인 및 변경 이력 관리 |
| 웹서버·배포 | Docker, Nginx |
| 인프라 | AWS EC2 |
| 도메인·보안 연결 | DuckDNS, HTTPS(TLS) |
| 형상 관리 | Git, GitHub |

**서비스 구조**

```text
사용자 브라우저
      │
      ▼
https://munongsa.duckdns.org
      │
      ▼
AWS EC2 / Nginx / Docker
      │
      ├── 웹 화면 (HTML·CSS·JavaScript)
      └── 공개 데이터 (JSON)
                  ▲
                  │ 검토·승인 후 공개
        서버 운영 데이터 및 수집 작업
                  ▲
                  │
          공식 농업정보 제공기관
```

웹 화면과 운영 데이터 수집·검토는 구분되어 있습니다. **저장소의 Docker 이미지만 실행한다고 AWS의 운영 DB, 예약 수집, HTTPS 인증서 설정까지 자동으로 복원되는 것은 아닙니다.**

## 7. 로컬 실행

### Docker로 정적 웹서비스 실행

프로젝트 루트에서 다음 명령을 실행합니다.

```bash
docker build -t munongsa:local .
docker run --rm -d --name munongsa -p 127.0.0.1:8080:80 munongsa:local
```

브라우저에서 **http://localhost:8080**에 접속합니다.

```bash
docker stop munongsa
```

Docker 없이 확인하려면 VS Code Live Server 등 로컬 HTTP 서버로 `index.html`을 제공할 수 있습니다. `file://`로 직접 열면 JSON 파일 로딩이 제한될 수 있습니다.

`app.py`는 별도의 Flask 시연 앱으로, 위 Docker 정적 웹서비스에 포함되지 않습니다.
