## 프로젝트 소개

농업 지원사업 정보는 기관·지역별로 분산되어 있고 신청 대상과 모집기간도 다릅니다. 무농사는 사용자의 영농 상황에 관련된 지원사업을 탐색하고, 농업금융 제도와 공식 재배기술 자료까지 한곳에서 살펴볼 수 있도록 만든 **중간발표용 MVP**입니다.

공식 출처와 확인 가능한 조건을 우선 안내합니다. **맞춤 비교 결과는 신청 자격의 확정 판정이 아니며**, 공고의 실제 접수 가능 여부·금융 승인·재배기술의 개별 적용 가능성을 보장하지 않습니다.

## 프로젝트 목표와 판단 기준

### 해결하려는 문제

초보·청년 농업인은 기관별로 흩어진 지원사업을 찾아야 하고, 자신이 대상인지·현재 신청 가능한지·어디에서 신청하는지 판단하기 어렵습니다. 농업금융과 재배기술 역시 별도 공식 사이트를 탐색해야 합니다. 무농사는 **공식 정보를 대체하는 서비스가 아니라, 자신의 상황에 관련된 공식 정보와 다음 행동을 찾도록 돕는 탐색·비교 서비스**를 지향합니다.

**핵심 사용자 흐름:** 영농 상황 입력(최소한의 조건) → 지원사업·금융·재배기술 탐색 → 관련 이유와 확인 필요 조건 이해 → 공식 원문·신청처·상담 경로로 이동.

### 발표 목표

| 시점 | 목표 | 평가 기준 |
| --- | --- | --- |
| **2026-11-02 중간발표** | 작동하는 MVP와 운영 구조 입증 | 지원사업 탐색·맞춤 비교·금융 4개·재배기술·모바일·자동수집 구조 시연 |
| **2026-12-07 최종발표** | 사용자 가치·정보 신뢰성 검증 | 공고 원문 검증, 추천 조건 테스트, 실제 사용자 탐색 테스트, 오류 개선 전후 비교, 운영 기록 |

**중간발표에서 미달성 또는 미확인인 목표:** 최초 목표 중 '모집 중 공고 10건 이상'은 **달성 확인되지 않았습니다.** 공개 11건과 기재 모집기간 내 9건은 실제 접수 가능한 10건을 의미하지 않습니다. 원문 검증 완료율과 실제 모집 상태를 과장하지 않습니다.

### 개발 과정

1. **노지 지원사업 안내 챗봇 구상** → 검색·비교 중심의 웹서비스로 전환.
2. **범위 조정** → 지원사업을 핵심으로, 농업금융·재배기술을 연결 서비스로 설정. 장비·자재 추천은 중간발표 핵심 범위에서 제외.
3. **공식 자료 수집·구조화** → 운영 DB, 중복·변경 탐지, 검토·승인 후 공개 구조 마련.
4. **UI·맞춤 비교 개선** → 검색·필터·D-day·상세·모바일·조건별 일치/불일치/미확인 안내.
5. **운영 인프라 구축** → AWS·Docker·Nginx, HTTPS, DuckDNS, 소유확인·SEO 설정.
6. **다음 단계** → 기능 개수 확대보다 원문 검증·추천 정확도·실사용자 검증에 집중.

## 로컬 실행

### 정적 웹사이트

VS Code의 Live Server 또는 다른 로컬 HTTP 서버로 `index.html`을 제공합니다. `file://`로 직접 열면 `fetch()`를 통한 JSON 로드가 제한될 수 있습니다.

### Docker

```bash
docker build -t munongsa:local .
docker run --rm -d --name munongsa -p 127.0.0.1:8080:80 munongsa:local
```

`http://localhost:8080`에서 확인하고, 종료할 때 `docker stop munongsa`를 실행합니다. 이 명령은 **로컬 정적 화면 검사용**이며 실제 AWS의 인증서·프록시·자동수집 구성을 재현하지 않습니다.

### 별도 Flask 시연 앱

```bash
python -m pip install Flask
python app.py
```

`app.py`는 정적 무농사 웹서비스와 별개의 시연 앱입니다. 개발용 `debug=True` 설정을 공개 운영에 사용하지 않습니다.
