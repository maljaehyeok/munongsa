## 프로젝트 소개

농업을 시작하려면 여러 기관에 흩어진 공고와 금융제도, 재배기술 자료를 각각 찾아야 합니다. 관련 자료를 발견해도 **내 상황에 해당하는지, 무엇을 추가로 확인해야 하는지, 어디에서 신청하거나 알아볼 수 있는지** 판단하기 어렵습니다.

무농사는 이러한 탐색 과정을 하나의 서비스로 연결합니다.

> **관련 정보 탐색 → 확인 가능한 조건 비교 → 필요한 준비사항 확인 → 공식 원문·기관 연결**

**무농사는 최종 신청 자격이나 대출 승인 여부를 판정하는 서비스가 아닙니다.** 확인된 공식 조건과 추가 확인이 필요한 사항을 구분하여, 사용자가 다음 행동을 판단할 수 있도록 돕습니다.

## 주요 기능

### 1. 농업 지원사업

- **공고 탐색:** 사업명·지역·작물·모집 상태 등을 기준으로 관련 자료 검색
- **조건 비교:** 영농지역, 신청자 유형, 농업경영체 등록 등 사용자가 입력한 조건과 **승인된 일부 공식 자격조건** 비교
- **결과 구분:** 확인된 조건의 일치·불일치와 추가 확인 필요 사항 표시
- **신청 준비:** 확인 가능한 제출자료·접수 안내 및 공식 원문 연결

공고의 관련성은 **신청 자격 확정**과 다릅니다. 공고의 실제 접수 상태와 모든 자격요건은 해당 기관의 최신 원문을 기준으로 확인해야 합니다.

### 2. 농업금융

**공개된 16개 금융·지원 제도**를 자금 목적에 따라 검색하고, 확인 가능한 조건과 공식 안내를 살펴볼 수 있습니다.

- 농업 창업·시설 투자·농지 마련·주택 관련 자금
- 대출 보증, 농지 지원·농지연금 등 성격이 다른 제도
- 제도별 대상·용도·한도·금리·상환조건 중 **근거가 확인된 정보** 안내
- 질문한 제도의 승인 정보를 활용하는 AI 상담 연계

제도별 확인 가능한 정보의 범위는 다릅니다. **미확인 금리나 현재 접수 여부는 임의로 확정하지 않으며**, 제도상 한도는 개인별 실제 승인 가능 금액을 뜻하지 않습니다. 기존 후계농 자금의 이자 계산도 명시된 가정에 따른 단순 계산으로, 실제 상환액이나 심사 결과가 아닙니다.

### 3. 재배기술

- **67종 작물·8개 분류**에서 작물명·별칭 검색
- 대표 작물 8종을 먼저 보여주고 필요할 때 전체 목록 탐색
- 작물 및 주제별 공식 재배·병해충·농약·토양 정보 연결
- 선택한 작물·주제의 탐색 상태 유지, 실제 영농 프로필과 임시 탐색 구분

농사로, 국가농작물병해충관리시스템, 농약안전정보시스템, 흙토람 등 공식 자료를 연결합니다. 작물·주제마다 직접 연결되는 자료 범위가 다르고, 외부 사이트에서 추가 입력이 필요할 수 있습니다.

### 4. AI 농업 상담

- 자연어로 지원사업·금융·재배기술 탐색
- 지역·관심 분야·검색 조건 수정 및 후속 질문
- 이전 공고나 금융제도를 가리키는 대화 맥락 유지
- 실제 영농정보와 임시 질문·가정 구분
- 기본 농업 개념 설명 및 필요한 경우 공식 자료로 안내

상담은 **규칙 기반 기능과 제한적인 OpenAI API 호출**을 함께 사용합니다. 일반 개념 설명과 공식 사업의 자격·금리·한도는 구분하며, 호출 실패나 한도 도달 시 가능한 범위에서 기본 안내로 복구합니다. 모든 질문에 GPT 응답이 제공되는 것은 아닙니다.

## 사용 흐름

1. **내 상황 입력:** 농업을 준비하거나 운영하는 지역·상황 등 필요한 조건 선택
2. **자료 탐색:** 관련 지원사업·금융·재배기술 검색
3. **조건 확인:** 확인된 사항과 미확인 사항을 구분
4. **공식 안내 확인:** 각 사업·제도의 원문과 담당 기관으로 이동

예를 들어 전북에서 토마토 재배를 준비하는 사용자는 관련 지원사업을 살펴보고, 필요한 자금제도를 탐색한 다음, 토마토 재배기술 자료까지 이어서 확인할 수 있습니다.

## 기술 구성

| 영역 | 구성 |
| --- | --- |
| 웹 프런트엔드 | HTML · CSS · JavaScript |
| 상담 API | Python · 규칙 기반 탐색·비교 · OpenAI API 연동 |
| 데이터 처리 | Python 수집·검토 스크립트 · JSON · 서버 운영 DB |
| 운영·배포 | AWS EC2 · Docker · Nginx · HTTPS |
| 개발 관리 | Git · GitHub |

```text
공식 기관의 농업정보
        ↓
정기 수집 및 변경 감지
        ↓
원문·조건 검토 및 공개 승인
        ↓
승인된 공개 데이터 ──→ 웹 화면 (HTML/CSS/JS)
                               │
                               └── Python 상담 API
                                      ├── 규칙 기반 탐색·비교
                                      └── 필요한 경우 OpenAI API
```

원본 운영 DB, 비공개 승인 근거, 수집 예약 작업, 상담 API 및 HTTPS 운영 설정은 정적 웹 자원과 분리되어 있습니다. **저장소의 Docker 이미지만 실행해 실제 운영 전체가 자동 재현되지는 않습니다.**

## 로컬에서 웹 화면 실행

저장소 루트에서 정적 웹 이미지를 빌드하고 실행할 수 있습니다.

```bash
docker build -t munongsa:local .
docker run --rm -d --name munongsa -p 127.0.0.1:8080:80 munongsa:local
```

브라우저에서 **http://localhost:8080**에 접속합니다.

```bash
docker stop munongsa
```

정적 웹 화면을 확인하는 용도이며, 실제 운영 상담·비공개 데이터·정기 수집 기능은 별도 서버 구성이 필요합니다.

운영 관련 문서: [상담 API 배포](deploy/chatbot/README.md) · [수집기 운영](deploy/collector/README.md)

### 이용 시 유의사항

무농사는 **지원사업 신청 자격·실제 접수 여부·금융 승인·개별 재배기술 적용 가능성을 보증하지 않습니다.** 최종적인 신청·금융·농약 사용 등 중요한 결정은 해당 기관의 최신 공식 안내와 실제 적용 조건을 기준으로 확인해야 합니다.
